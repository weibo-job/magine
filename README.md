# Magine

Magine 是一个本地优先的 AI 创作工作台：把“想法、讨论、页面 Demo 和视觉素材”放进同一条可迭代的创作流程。

## 它解决什么问题

普通 AI 对话通常只能给出一段文字，Magine 更关注从想法到成果的连续过程：

1. 在「圆桌思辨」里让产品、设计、前端和反方角色逐轮讨论。
2. 识别事实、技术、偏好和目标分歧，并给出验证或暂定推进方案。
3. 页面类方案进入「页面方案工作台」，先生成可看的 HTML Demo。
4. 在 Demo 下继续提出修改，带着 Demo 回圆桌讨论，再返回工作台迭代。
5. 满意后确认交付，再导出 React 页面代码。
6. 图像、视频、音乐等媒体方案可以发送到自由画布，继续组成节点式工作流。

## 核心优势

- **先讨论，再落地**：不是直接吐代码，而是先形成结构、组件、交互和动效方案。
- **Demo 驱动迭代**：先看真实页面预览，再决定是否需要继续讨论或交付。
- **分歧处理机制**：遇到分歧时优先核验、实验、对比或暂定推进，不把每个小问题都丢给用户。
- **无限画布工作流**：Prompt、LLM、图像、视频、音乐和 Agent 节点可以连线协作。
- **本地优先**：API Key、圆桌草稿、Demo 历史和资产默认保存在本地。

## 当前状态

当前版本是一个可运行的桌面端原型，已包含：

- 圆桌思辨：答疑、头脑风暴、方案落地、证据与验证
- 多轮讨论、暂停、用户插入观点、参考图视觉分析
- 页面方案工作台、Demo 版本历史、全屏预览、浏览器预览
- 页面 Demo 与圆桌之间的往返迭代
- React 页面代码导出
- 自由画布节点编排、资产保存、提示词预设
- 图像、视频、音乐和部分视觉处理节点

## 开始运行

```bash
npm install
npm run dev
```

构建桌面端资源：

```bash
npm run build
```

启动后在「设置」中填写你自己的模型 API Key。项目不会把 API Key 提交到仓库。

## 技术栈

- React + TypeScript
- Vite
- Electron
- React Flow
- Three.js
- GSAP

## 说明

这是一个个人创作工具原型，部分媒体模型能力依赖用户自己的服务商权限和 API 配置。Demo 预览默认使用无外部资源的沙箱 HTML；公网分享、云端协作和部署能力仍在后续规划中。
